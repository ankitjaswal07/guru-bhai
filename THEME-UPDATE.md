# English theme and reference chart staging

Install `guru-bhai-khaiwal.zip` via **Appearance → Themes → Add New → Upload Theme** and activate the existing Results Manager plugin (`scheduled-results-manager.zip` is unchanged). The theme retains its plugin shortcode integration and uses local CSS and lightweight JavaScript.

In **Appearance → English demo import**, create the missing English pages, game chart pages and articles. Tick **Refresh previously imported, unedited demo pages and articles** to update content created by this importer since version 2.4.0. Pages modified since import (including ACF Page Sections) are not overwritten. Older demo pages without an import fingerprint are preserved and must be reviewed manually. Menus, independent pages and plugin results are not overwritten.

The same screen can stage a snapshot of a selected **A1-Satta game and year** if the reference page exposes a parseable twelve-month HTML table and the game's slug already exists in Results Manager. This requires PHP DOM and server-side HTTP access to the reference. The import is deliberately limited to one game/year per action, skips blanks and invalid dates, records source attribution, and never overwrites or automatically publishes existing results. Review every pending row under **Results Manager → Historical import & review** before publishing. If a chart cannot be parsed, obtain a verified CSV and use the plugin's existing CSV import. The theme does not ship or claim a complete, current copy of the reference site's results; no automatic synchronization is configured.

The same demo form has an opt-in checkbox to stage all 523 bundled historical rows through the plugin’s own importer. They remain pending and must be individually verified and published in Results Manager. This dataset covers only 26 August–26 October 2026, 11 of 14 bundled games; it is not a full reference-site archive. ACF PRO is needed for visual theme options and editable page sections. Set **Settings → General → Site Language** to English for WordPress dates/UI. Previously saved Hindi settings, pages and plugin game names are not automatically translated. The supplied theme is a responsive adaptation, **not a pixel-perfect replica** of the reference website.

The theme also includes a redesigned responsive homepage with quick navigation cards, refined typography, mobile table scrolling and improved keyboard focus states. It does not change plugin shortcode names or plugin files.
